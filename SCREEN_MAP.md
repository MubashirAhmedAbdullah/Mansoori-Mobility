# Mansoori Mobility screen map

| URL | Screen / role |
|---|---|
| `/` | Public landing page, service selector and quick search |
| `/login` | Sign-in form and role-based workspace preview |
| `/signup` | Registration form and role selection |
| `/freight` | Freight marketplace sample search/results |
| `/rentals` | Rental customer search, category and price filters |
| `/shipper` | Goods-owner dashboard, shipment overview, route progress, activity and quick actions |
| `/shipper/post-load` | Multi-step shipment request form and summary |
| `/shipper/shipments` | Shipment records and status filter |
| `/shipper/quotes` | Quote/offer comparison records |
| `/carrier` | Carrier metrics, recommended loads, earnings and fleet readiness |
| `/carrier/marketplace` | Filter freight requests and prepare a quote (demo interaction) |
| `/carrier/loads` | Carrier booked-load records |
| `/carrier/fleet` | Fleet and vehicle records |
| `/carrier/drivers` | Driver roster and licence status |
| `/driver` | Current trip, vehicle details and milestone checklist |
| `/driver/jobs` | Assigned job records |
| `/host` | Rental-host dashboard and reservations |
| `/host/vehicles` | Rental inventory records |
| `/host/calendar` | Vehicle availability calendar records |
| `/host/reservations` | Rental booking records |
| `/admin` | Platform control room with metrics, charts, KYC queue and exceptions |
| `/admin/users` | Verification queue records |
| `/admin/bookings` | Booking review records |
| `/admin/vehicles` | Vehicle moderation records |
| `/admin/disputes` | Dispute and evidence review records |
| `/admin/reports` | Report list |
| `/admin/settings` | Commission/policy configuration view |
| `/admin/audit` | Audit history records |
| `/finance` | Finance overview and settlement ledger |
| `/finance/payouts` | Provider payout queue records |
| `/finance/refunds` | Refund review records |
| `/finance/reconciliation` | Reconciliation exception records |
| `/payments` | Customer payment activity and settlement workflow |
| `/support` | Support landing page, demo tickets and contact request form |

The pages are responsive and share common components. Dashboard rows and many buttons are deliberately sample/demo interactions until the relevant actions are connected to persistent data and external providers.
